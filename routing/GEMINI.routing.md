# SuperSpecFlow 轻量路由

宿主项目的业务规则、架构事实和本地约束优先。SuperSpecFlow 只选择当前任务需要的方法，不接管项目，也不要求安装 OpenSpec 或 Superpowers。

## 默认执行

- 问答和只读检查直接处理，不创建流程文件。
- 用户明确要求实现、修复或重构时，先定位现有代码，再做最小修改、针对性验证和 diff 检查。授权在当前会话的同一范围内持续有效。
- 普通功能在会话内说明目标、边界和验收点即可；不强制 change-id、Spec ID、规格映射、阶段签字或独立计划。
- 跨模块或跨会话任务只维护一份计划：优先复用用户指定或项目已有文件，否则使用 `docs/plans/<topic>.md`。内容包括目标、边界、任务、验收、进度和必要风险，不另建 progress、handoff、map 文件。
- 只有无法从会话和仓库推断、且会实质改变业务结果、范围、外部契约、费用或可见范围的问题才询问；继续不依赖答案的工作。普通技术选择和测试边界由 agent 判断。

## 按需能力

| 请求 | 按需入口 |
|---|---|
| 讨论产品、方案或不清楚的需求 | `ssf-think`，只澄清关键问题 |
| 要求计划、规格或拆任务 | `ssf-plan`，默认一份简短计划 |
| 实现、修 bug、重构 | `ssf-build`，按需读取其 TDD / 调试参考 |
| 审查代码 | `ssf-review`，检查正确性和需求符合度 |
| 测试、验收、浏览器或视觉核验 | `ssf-qa`，验证与结论范围一致 |
| 发布准备或执行发布 | `ssf-ship`，区分建议与已授权的实际操作 |
| 分支、提交、PR | `ssf-git`，按当前请求执行 |

这些入口可独立使用，按当前需求独立执行。默认在当前会话完成工作，不强制多 agent、worktree、issue tracker、访谈或计划评审循环。

## 必要纪律

- 遵循 Karpathy 纪律（编码前思考、简单优先、外科手术式修改、目标驱动执行）与 mattpocock 实战方法（TDD、根因诊断、代码审查）。只修改目标所需内容，保护无关未提交工作，优先复用项目机制，避免推测性抽象。
- 本次新增或行为、契约发生变化的函数必须在实现定义处写简体中文函数级注释，说明功能及实际适用的输入输出语义、约束；仅格式调整不补注释，不补写无关历史代码。
- 测试观察公开接口的行为，不复制实现逻辑。缺陷优先建立能捕获该症状的复现或测试，小步修改后复验。测试方式遵守宿主构建和运行限制。
- 验证应覆盖受影响的主要路径、关键负向路径和相关回归。只运行适当检查，不为填表新增低价值测试。
- 完成前核查实际 diff，说明做了什么、验证了什么、还缺什么。静态检查、测试、构建、浏览器、真机和部署证据不能互相冒充；未运行不得写通过。
- Review 先核实事实再修复。普通审查直接进行；用户要求独立审查且工具可用时再委派，不制造虚假独立结论。
- 中文交流和文档；commit / PR 标题使用 `<英文类型>(<英文范围>): <中文摘要>`，正文按需中文说明变更、验证和风险；不要求编号字段。
- 提交前检查 `git status --short`、`git diff --stat`、`git diff --check` 和 staged diff；按明确路径暂存。实现完成不自动 commit、push、PR 或发布，已有明确授权除外。

## 风险与授权

根据实际操作影响判断风险，不因提到“数据库”“权限”就强制整套流程。支付、权限、认证、用户数据和迁移等变更应验证相关失败、越权和数据一致性路径；实际发布或迁移按需补充回滚方法、恢复限制和观测信号，写在同一计划或现有发布记录即可。

生产发布、远端写入、删除、权限变更、凭据使用、付费和素材外传必须在实际授权范围内执行；复用已有授权，不新增重复确认。缺少授权时先完成可审阅的准备工作，沉默或超时不代表同意。

## 接入

全局安装默认全局开启轻量自然语言路由，无需在每个项目中执行 init。若项目需要单独禁用，可在项目根目录放置 `.superspecflow/disabled`。项目可通过自己的 `.superspecflow/AGENTS.routing.md` / `CLAUDE.routing.md` / `GEMINI.routing.md` 自定义规则覆盖默认路由；显式 include 也可接入。恢复已禁用项目：Claude 运行 `/ssf-init`，Codex 与 Antigravity 执行 `bash <pack>/scripts/_ssf_init_apply.sh`。不覆盖宿主 AGENTS.md / CLAUDE.md / GEMINI.md。
