# ssf-ship

“能否上线”只评估；实际发布、迁移、远端写入按会话已有授权执行。未获授权先完成可审阅的准备，不重复请求同一范围的授权。

检查实际 diff、相关验证结果、未解决问题、目标环境与配置。支付、权限、数据迁移等风险按实际影响补充负向验证、回滚或恢复方法、不可逆限制和观测信号，可写入已有计划或发布记录，不强制一套阶段文件。

缺少关键验证、授权或可行恢复措施时说明具体阻塞，不能靠填满模板宣称可发布。可用 `templates/release-checklist.md` 记录。只有实际执行并读回结果，才能宣称已发布；部署完成不能代替真实业务验收。
