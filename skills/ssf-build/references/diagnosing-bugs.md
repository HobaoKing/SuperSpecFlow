# 按需调试

采用 mattpocock/skills 的复现反馈、缩小场景、验证假设和回归方法，取消固定阶段审批及固定假设数量。

1. 建立与用户症状对应的反馈信号：优先现有测试、最小请求、CLI fixture 或现有浏览器/设备会话。确认捕获的是原始问题，不只是“没有崩溃”。
2. 缩小仍能复现的输入和调用链。异步问题明确触发次序；性能问题先记录可比较的基线。不要未经授权对生产施压或添加采集。
3. 根据证据提出可证伪假设，每次改变一个关键变量，用调试器或定向日志验证。日志和输出去除凭据及个人敏感信息。
4. 在能覆盖实际故障链的边界补回归测试，最小修复后重跑原始场景和相关回归。清理本次临时插桩，保护已有诊断工具。
5. 无法复现时明确哪些是静态判断、哪些已实际验证，继续安全的代码检查；只在必要时请求缺失环境信息，不猜测后声称已修复。
