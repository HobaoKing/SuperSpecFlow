# Proposal: add-membership-renewal-reminder

## Summary

在会员中心为即将到期的会员展示续费提醒，并允许用户关闭本轮提醒。

## Problem

用户经常在会员权益到期后才发现服务中断，客服需要人工解释续费入口和到期时间。

## Goals

- 到期前 7 天内提示续费。
- 提供明确续费入口。
- 允许用户关闭本轮提醒。
- 记录提醒展示和关闭事件，便于评估效果。

## Non-goals

- 不改变支付、订阅、退款或计费逻辑。
- 不新增营销推送、短信或邮件。
- 不修改会员价格、套餐或权益。

## User Impact

即将到期的会员能提前看到续费入口，减少权益中断。

## Affected Areas

- 会员中心页面。
- 会员状态读取。
- 埋点事件。

## Success Metrics

- 到期前续费入口点击率可被统计。
- 客服关于“会员到期后找不到续费入口”的咨询量下降。

## Risks

- 非会员误看到续费提醒。
- 已关闭提醒的用户被重复打扰。
- 到期时间计算错误导致过早或过晚提醒。

## Rollout Strategy

先在会员中心单入口上线，不触达站外渠道。若指标和反馈稳定，再考虑扩展到其他入口。
