# 计划：会员续费提醒的展示判断

## 目标与边界

会员中心需要知道是否显示续费提醒。本示例只实现无副作用的展示判断，不代表完整会员功能交付。

- 是会员、未关闭本轮提醒，且实际剩余时间在 `(0, 7×24小时]` 时展示。
- 非会员、已关闭、本期已到期、距到期超过七天或缺到期时间时不展示。
- 当前时间由调用方传入，参与比较的时间必须带时区；缺时区时报错，避免依赖机器环境。
- `dismissed` 是调用方提供的当前会员周期状态。UI、关闭状态持久化、跨周期重置、埋点和推送不在本示例范围；支付、订阅和计费逻辑不变。
