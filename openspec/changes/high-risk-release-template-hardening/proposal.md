# Proposal: high-risk-release-template-hardening

## Summary

Strengthen risk, rollback, and monitoring templates so high-risk changes have owner, mitigation, detection, waiver, residual risk, and drill fields.

## Problem

Current release templates are too thin for payment, auth, data, security, and production release workflows.

## Goals

- Expand `risk-matrix.md`.
- Expand `rollback-plan.md`.
- Expand `monitoring-plan.md`.
- Validate required high-risk fields.
