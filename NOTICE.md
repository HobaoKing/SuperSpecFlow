# NOTICE

SuperSpecFlow integrates ideas from several open-source AI software-development workflows:

- OpenSpec-style spec-driven change contracts.
- Superpowers-style agentic engineering discipline.
- gstack-style role-based product, engineering, QA, and release review gates.
- Karpathy-inspired coding discipline from `multica-ai/andrej-karpathy-skills`: think before coding, simplicity first, surgical changes, and goal-driven execution.

The bundled `ssf-karpathy` skill is an adapted workflow layer, not a verbatim copy of the original repository.
