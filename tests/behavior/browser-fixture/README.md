# 通知设置测试页

候选版本：browser-fixture-1。仅用于隔离验收，没有生产账号或真实通知服务。

用户契约：
- 受限账号无编辑权，保存被拒绝时明确显示失败，刷新后仍为原值。
- 成员账号可保存开关，成功后刷新仍保留；切换账号应显示所选账号的状态。
- 桌面和 390 像素窄视口均应可以操作开关和保存按钮。底部说明不应妨碍操作。

运行方式：评估者执行 `/usr/bin/python3 -B server.py`，获得随机回环端口后交给执行者。只对评估者启动的进程操作。服务端将请求和结果写入 runtime/events.jsonl，状态写入 runtime/state.json；日志只含虚构测试账号和布尔值。初始两个账号开关均关闭。运行时日志可辅助浏览器证据，不能代替实际交互。

没有基线截图，不要求像素一致性通过。只验收，不修改实现，不提交。
